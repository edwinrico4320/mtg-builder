# Output Profiles — v8.7.1

## Normal catalog
Full card-oriented presentation with responsive navigation and embedded/external image options.

## Printable catalog
Dense print-oriented output. The default target is 30 summaries per printed side, or up to 60 on a duplex physical sheet.

## Micro catalog preview
A tuning view for the 30-card target. It exposes collector/reference/rules density, cropped/full/no artwork, compact/full/hidden Oracle text, flavor visibility, price detail, artist visibility, and stats visibility.
