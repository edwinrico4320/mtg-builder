RULES LIBRARY SOURCE SETUP

1. Download the current official Comprehensive Rules TXT from the Wizards rules page.
2. Rename it to MagicCompRules.txt.
3. Upload it to this data/rules folder beside index.json.
4. Open the Rules Library tab in the builder.
5. Leave the source as ./data/rules/index.json and click Build Rules Library.

Recommended output: Hybrid ZIP — Chapters + All Rules.

The official rules text is not included in this package.
